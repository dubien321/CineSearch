CinéMatch - Application de films
Description

CinéMatch est une application web permettant de rechercher et de découvrir des films à travers une interface interactive.

L'application récupère les informations des films depuis une API et les affiche dynamiquement dans la page.

Fonctionnalités

- Affichage dynamique des films
- Recherche de films
- Affichage des informations d'un film
- Affichage de l'affiche du film
- Affichage du titre
- Affichage de la description
- Affichage de la note
- Filtrage des résultats
- Gestion des erreurs
- Affichage d'un message lorsqu'aucun résultat n'est trouvé
- Interface responsive

Technologies utilisées

- HTML5
- CSS3
- JavaScript
- DOM
- Fetch API
- API REST
